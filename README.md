# WebApps Demo

This repository collects the university web-app lab exercises into a single demo project.

## Included apps

- Intro lab (`projects/intro`)
- Todo app (`projects/todo`)
- Map puzzle (`projects/puzzle`)
- Weather app (`projects/weather`)
- Custom PHP framework (`projects/php-framework`)

## Demo entry point

Open `index.html` in the repo root to access a simple navigation page that links to each project.

## Notes

Each project is kept in its own folder so it can be developed or reviewed independently, while the root page acts as a demo hub.
